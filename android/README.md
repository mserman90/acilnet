# AcilNet - Gercek Calisan Mesh Uygulamasi

Bu Android Studio projesidir. Web sitesi degil, telefonda calisan BLE+WiFi mesh uygulamasidir.

## Calistirma
1. Android Studio -> Open -> bu klasor
2. Sync Gradle
3. Telefona bagla -> Run

## Ozellikler
- BLE mesh tarama + Nearby Connections (WiFi Direct)
- 4 seviye SOS: Guvendeyim, Ihtiyac, Yarali, Enkaz
- Enkazda 3.1kHz duduk + Mors SOS flasor
- 7 hop flood routing
- Radar: RSSI dBm + mesafe tahmini
